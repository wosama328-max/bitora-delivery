# Bitora Delivery 🚚

تطبيق السائقين الرسمي لنظام **Bitora Agancy POS** — وحدة التوصيل.

يستلم السائق طلبات التوصيل فور إنشائها من البرنامج، يستلم الطلب بضغطة واحدة، يتابع المسار على الخريطة (OpenStreetMap/MapLibre بدون أي مفاتيح API)، ويحدّث حالة التوصيل خطوة بخطوة حتى التسليم — مع إشعارات فورية بالصوت والاهتزاز لكل طلب جديد.

## أحدث إصدار

حمّل ملف الـ APK من صفحة [Releases](https://github.com/wosama328-max/bitora-delivery/releases/latest) وركّبه على الموبايل (اسمح بتثبيت التطبيقات من خارج المتجر).

## المتطلبات

- حساب سائق يُنشأ من داخل برنامج Bitora POS ← صفحة التوصيل ← تاب السائقين.
- Android 8.0 أو أحدث.

## ملاحظات

- التطبيق يعمل بشكل مستقل تمامًا عن تشغيل المطعم — إيقافه لا يؤثر على الـ POS.
- الموقع الجغرافي يُستخدم فقط أثناء وجود طلب توصيل نشط.
